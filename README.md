## 🚀 Featured Projects

### 🔷 AWS Resource Provisioning via Jenkins + Ansible + Kubernetes
> **Stack:** Jenkins · Ansible · Kubernetes · AWS EC2 · GitHub · Linux · SSH · SCP

- Designed a **3-tier CI/CD pipeline** on AWS EC2 integrating Jenkins, Ansible, and Kubernetes — eliminating all manual provisioning steps
- Configured Jenkins with 3 automated stages: GitHub checkout → SCP file transfer to Ansible server → remote playbook execution via SSH
- Built `ec2.yml` Ansible playbook using `amazon.aws` collection for programmatic EC2 provisioning (security groups, AMI, key-pairs)
- Established **passwordless SSH** between Ansible and Kubernetes nodes via key-pair + `authorized_keys` — verified with `ansible -m ping` returning 0 failures
- Managed 3 EC2 instances (`t3.micro` × 2, `c7i.flex.large`) in `ap-south-1` via MobaXterm multi-node sessions
